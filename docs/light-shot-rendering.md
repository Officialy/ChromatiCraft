# Light Shot rendering source contract

V33a Render/Entity/RenderLightShot.java draws a white CHROMA quad at radius .25
and depth 0 with DEFAULT alpha blending, then a colored SPINFLARE quad at radius
.6 and depth -.05 with ADDITIVEDARK RGB screen blending. Both disable directional
lighting, retain packed brightness 240 (block light 15 / sky light 0), disable
alpha testing and depth writes, and keep scene depth testing.

The port now submits both materials through the native composed-scene phase,
with explicit collector orders 0 (spark) and 1 (flare). This retains the source
layer sequence when the native renderer batches different render types. The
spark uses EntityLighting.LIGHTMAP_ONLY.alphaSprite: ordinary alpha with no
ALPHA_CUTOUT define. The original chroma_particle PNG contains faint alpha bytes,
so a .1 cutout would lose part of the source image. The new forward alpha material
supports all four existing independent lighting modes and both culling settings;
its world callers must choose the native forward phase. The flare retains the
lightmap-only screen material. Its source PNG is fully opaque in alpha.

Both icons resolve through ChromaIcons in the animated block atlas. This restores
Minecraft-managed animation and metadata instead of manually selecting wall-clock
rows from a standalone 180-frame texture. The source assets have 128 CHROMA frames
at frametime 2 and 180 SPINFLARE frames at frametime 1. Resource packs can supply
their own atlas animation metadata without a hardcoded renderer frame count.

The source palette is the original 32 ChromaFX colors followed by their reverse,
blended over five ticks per color. Pulse is exactly .8 + .2*sin((millis/mod)%360),
where mod is 15 + entityId%15; the sine argument remains radians as in the source.
The whole-tick color/pulse is captured once during extraction. Current entity
position is captured separately from native interpolated placement for the source
polar billboard bearing. Removed/coincident-camera cases retain a finite
unrotated pose. Deferred draws capture their sprite, color and pose.

LightShotClientChecks compares 144 goldens generated by JDK 25 from the original
palette, ColorBlendList, mix and brightness method bodies, plus 96 independent
geometry/blend/color/bearing fixtures. It verifies original animated atlas metadata,
all eight no-cutout alpha GPU variants, source light/depth states, real extraction,
ordered native classic/improved forward queues and immutable replay.
LightShotSceneClientChecks delegates the registered renderer for an actual
client-only projectile and observes both ordered callbacks completing classic
and improved world frames. It discards its projectile and restores camera/options;
normal production particle lifetimes remain in effect. This does not establish
final framebuffer, cross-entity compositing, or external shader-pack pixel parity.
